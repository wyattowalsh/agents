## Installing Individual Skills

You can also install specific skills rather than the full collection:

```bash
# Install a single skill globally
npx skills add github:wyattowalsh/agents --skill review -y -g --agent claude-code --agent codex --agent crush --agent cursor --agent opencode

# Install multiple specific skills
npx skills add github:wyattowalsh/agents --skill review --skill wargame -y -g --agent claude-code --agent codex --agent crush --agent cursor --agent opencode

# Install to a specific agent only
npx skills add github:wyattowalsh/agents --skill orchestrator -y -g --agent claude-code
```

<Aside type="tip" title="Creating your own skills">
Want to build a custom skill? Use the [skill-creator](/skills/catalog/custom/skill-creator/) to scaffold, develop, audit, and package skills following proven structural patterns. Or run `wagents new skill my-skill` from the [CLI](/cli/).
</Aside>
