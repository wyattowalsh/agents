<Aside type="caution">
Cross-harness Tier B policy. Decision logic in `wagents/hooks/policies/git_commit_push_guard.py` (`evaluate_git_commit_push`) blocks force-pushes to protected branches, history rewrites, and hook-skipping commits (`--no-verify`, `--no-gpg-sign`). Each harness renders its own native deny shape; Grok consumes it via the fleet deny adapter.
</Aside>
