## Install

**Targeted** (preferred — do not full-catalog sync apply):

```bash
# Core
npx skills add backnotprop/plannotator/apps/skills/core \
  --skill plannotator-review --skill plannotator-annotate --skill plannotator-last \
  -y -g -a claude-code codex crush cursor opencode

# Extras
npx skills add backnotprop/plannotator/apps/skills \
  --skill plannotator-compound --skill plannotator-setup-goal --skill plannotator-visual-explainer \
  -y -g -a claude-code codex crush cursor opencode
```

Grok refresh (extras on by default):

```bash
uv run wagents grok plannotator install
# or: uv run wagents grok plannotator sync
```

Cursor Agent (IDE + CLI) home hooks (binary + shim; skills already via `-a cursor`):

```bash
uv run wagents cursor-cli plannotator install
# or: uv run wagents cursor-cli plannotator sync
```

<Aside type="caution" title="Do not">
Install from `backnotprop/plannotator` repository root. Use the `apps/skills/core` and `apps/skills` paths above. Avoid unbound `wagents skills sync --apply` when you only need Plannotator rows.
</Aside>

## Doctor

```bash
uv run wagents grok doctor --format json
uv run wagents cursor-cli doctor --format json
```

Core skills missing → hard fail path where configured. Extras missing → warn when extras are expected on by default.
