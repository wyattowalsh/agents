## Safety Notes

- **Credentials:** none required for core generation/export.
- **Network:** optional logo CDN fetch and diagrams.net fragment URLs; core authoring offline.
- **Files:** project reads for code/IaC visualization; diagram writes; optional `~/.drawio-skill` style presets.
- **Live action:** live terraform/docker/k8s importers and PR/timelapse tools can leak sensitive topology — invoke deliberately with redaction.
- **MCP / daemons / hooks:** none in the skill package; do not auto-start extras from this catalog row.
- **Secrets:** never commit secrets, tokens, private keys, connection strings, or raw cloud state dumps into diagrams or the repo.
